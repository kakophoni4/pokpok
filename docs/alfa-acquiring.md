# Подключение эквайринга Альфа-Банка

Текущая версия учитывает покупки отдельно от поступившей оплаты. Хостес может принять полную или частичную оплату наличными либо через терминал. Повтор операции с тем же requestId не создаёт второй платёж.

Автоматическая оплата по СБП пока не подключена. GET /api/live/acquiring/status возвращает available: false. UnconfiguredAcquiringGateway отказывает в создании ссылки и проверке оплаты с кодом ACQUIRING_NOT_CONFIGURED. Изменение страницы или нажатие игроком кнопки не погашает долг.

Для подключения заказчик должен предоставить документацию именно своего продукта эквайринга, тестовый доступ, идентификатор магазина и способ проверки уведомлений банка. Секреты передаются через окружение сервера, их нельзя добавлять в Git.

После получения доступа:

1. Реализовать AcquiringGateway по документации банка: создание оплаты и проверку её статуса.
2. Добавить хранение платёжных попыток с уникальным operationId и providerId. Сумму и владельца счёта определяет сервер.
3. Проверять подпись уведомления и подтверждать результат запросом к банку. Проверять магазин, валюту, сумму и идентификатор операции.
4. В одной транзакции записывать подтверждённую оплату и сообщение игроку. Повторное уведомление не должно менять баланс повторно. Для банковских оплат не использовать ручную отмену наличного поступления.
5. Проверить частичную оплату, повторные уведомления, истечение ссылки, оплату после отмены покупки, возвраты и восстановление после сбоя.

До выполнения этих проверок автоматическое погашение долга по СБП не включается.
