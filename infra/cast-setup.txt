CONCEPT: Google Cast / Android TV

Страница-приёмник уже размещена:
https://147-45-224-200.sslip.io/cast-receiver

Регистрация в аккаунте клуба:
1. Открыть https://cast.google.com/publish/ (Google Cast SDK Developer Console).
2. Add New Application → Custom Receiver.
3. Название: CONCEPT — экран зала.
4. Receiver Application URL:
   https://147-45-224-200.sslip.io/cast-receiver
5. Сохранить и передать Application ID (8 шестнадцатеричных символов).
6. Для проверки до публикации добавить телевизор в Cast Receiver Devices
   согласно инструкции Google. После публикации приёмник доступен другим
   устройствам Cast без регистрации каждого телевизора.

Настройка сайта администратором сервера:
Сохранить CAST_APPLICATION_ID=<ID> в /opt/poker/infra/.env.
Очередная сборка web использует этот ID через VITE_CAST_APPLICATION_ID.
Для включения без пересборки записать {"applicationId":"<ID>"}
в /srv/cast-config.json контейнера poker-league-web-1. Источник постоянной
настройки — .env; локальный JSON не должен быть единственным её хранилищем.

Работа флора:
Открыть /floor в Chrome на Android, войти логином и паролем.
Выбрать турнир → Подключение телевизора → Отправить на телевизор · Chromecast.
Выбрать Android TV в системном списке Google Cast. Телефон и телевизор
должны находиться в одной сети Wi-Fi с разрешённым обнаружением устройств.
На телевизор передаётся только экран зала и его ключ просмотра;
рабочая панель и авторизация флора остаются на телефоне.
Экран получает таймер напрямую с сервера: он не зеркалирует телефон.
Звук, возобновление после блокировки телефона и работу на конкретном
телевизоре необходимо проверить после регистрации Application ID.

Пока Application ID отсутствует, кнопка не запускает передачу и честно
показывает, что Chromecast ещё не настроен. Доступен вход на ТВ по коду /tv.
